## 🌾 Features
- **🌐 2 Languages (English & Telugu)**: Seamless language switcher with localized Telugu content and typography (`Noto Sans Telugu`).
- **🔍 Dedicated Availability Page (`availability.html`)**: Interactive page showing live stock status and specifications for 2 red gram varieties.
- **📸 2 Featured Seed Varieties with Photos**:
  1. **Dhanalakshmi Seeds (ధనలక్ష్మి కంది విత్తనాలు)**: Bold red, high-yielding variety.
  2. **Lakshmi Seeds (లక్ష్మి కంది విత్తనాలు)**: Drought-tolerant, farmer-trusted variety.
- **🔍 Photo Lightbox**: Click to enlarge and inspect seed photos in high resolution.
- **📊 Variety Comparison Table**: Side-by-side comparison of seed color, duration, yield, and disease resistance.
- **💬 Instant WhatsApp Enquiry**: Dynamic WhatsApp inquiry form with variety, quantity, and location pre-filled in English or Telugu.
- **👨‍🌾 Owner Profile**: Dedicated section featuring owner **B. Srinivasulu** and local background.
- **📍 Location & Maps**: Address with instant Google Maps directions to Rampalli.

## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Bodabandasrinath/red-gram-seeds.git
   ```
2. Navigate into the folder:
   ```bash
   cd red-gram-seeds
   ```
3. Open `index.html` in any web browser or serve locally:
   ```bash
   python -m http.server 8000
   ```
4. Visit `http://localhost:8000` in your browser.
